# Contributing to Pip's Dream OS

Thanks for helping! Everyone is welcome, including first-time contributors.

## Ways to help
- Report bugs (use the Bug template, include browser, device and steps)
- Request features (open an issue and describe the idea before coding)
- Fix issues labelled `good first issue` or `help wanted`
- Improve docs, accessibility and performance

## Setup
No build step. Open `index.html` and visit http://localhost:8000.

## Pull requests
1. Fork, then branch: `feature/short-name` or `fix/short-name`
2. Keep PRs small and focused, one change per PR
3. Test at desktop, tablet and phone widths with the console open (it must stay clean)
4. Include a screenshot or short recording for visual changes
5. Describe what changed and why

## Code rules
- Plain HTML, CSS and JS, no frameworks or new dependencies without discussion
- Keep modules in `js/`, and keep audio behind the existing mute switch
- Respect `prefers-reduced-motion` and keyboard access
- Credit any new art, sound or font in the README and footer

## Conduct
Be respectful and constructive. Harassment of any kind is not tolerated.
